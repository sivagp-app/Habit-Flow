# 🌟 Habit Flow - Your Personal Habit Tracker

A beautiful, easy-to-use habit tracking web app designed for everyone, with special ADHD-friendly features. Works on all devices.

## ✨ Features

### Core Features (Everyone Gets):
- ✅ **Simple Habit Tracking** - One-tap to mark habits complete
- 🔥 **Dual Streak Tracking** - Current streak + personal best
- 📊 **Visual Progress** - See your weekly progress at a glance
- ✏️ **Edit Habits** - Modify habits without losing progress
- 🏷️ **Categories** - Organize with 6 color-coded categories
- 📱 **Works Everywhere** - Phone, tablet, or computer
- 💾 **Offline Support** - Works without internet
- 🎨 **Beautiful Design** - Clean, modern interface
- 🔒 **Privacy First** - All data stored on your device

### ADHD Support Mode (Toggle ON):
- 🧠 **Celebration Animations** - Instant dopamine hits on completion
- 💬 **Encouraging Language** - Gentle, supportive messaging throughout
- 🎯 **Focus Mode** - Show only incomplete habits to reduce overwhelm
- 🔔 **Reminder System** - Set notification times for each habit
- ✨ **Extra Motivation** - Positive reinforcement at every step
- 🎉 **Random Celebrations** - Different encouraging messages each time

## 📦 Hosting on Netlify (Easiest!)

**Netlify is perfect for beginners - completely free, no credit card needed**

### Step-by-Step Instructions:

1. **Create a Netlify Account**
   - Go to: https://www.netlify.com
   - Click "Sign Up" (use your GitHub, GitLab, or email)

2. **Prepare Your Files**
   - Put all these files in ONE folder:
     - index.html
     - styles.css
     - app.js
     - manifest.json
     - service-worker.js

3. **Deploy Using Drag & Drop**
   - Log into Netlify
   - Look for "Sites" in the main dashboard
   - Find the **big dotted box** that says "Want to deploy a new site without connecting to Git? Drag and drop your site output folder here"
   - **Drag your entire folder** into that box
   - Wait 10-30 seconds...
   - Done! 🎉

4. **Get Your URL**
   - Netlify gives you a free URL like: `random-name-12345.netlify.app`
   - Click "Domain Settings" to change it to something like: `my-habit-tracker.netlify.app`

5. **Access Your App**
   - Visit your URL on any device
   - Bookmark it on your phone
   - Install it as an app (your browser will prompt you)

### Updating Your App on Netlify:
- Make changes to your files
- Go to your site on Netlify
- Click "Deploys" tab
- Drag your updated folder to the deploy area
- Done!

## 🎯 Using Your App

### First Time Setup:

1. **Open your app** (either locally or at your hosted URL)
2. **Click "+ New Habit"**
3. **Type a habit name:** "Drink 8 glasses of water"
4. **Pick an icon:** 💧
5. **Optional:** Choose a category (Health, Productivity, etc.)
6. **Optional:** Set a reminder time
7. **Click "Create Habit"**

### Accessing Settings:

1. **Click the gear icon (⚙️)** in the top right of the header
2. **Settings panel opens** with these options:
   - 🧠 **ADHD Support Mode** - Toggle for extra encouragement
   - 🎯 **Focus Mode** - Show only incomplete habits
   - 🔔 **Notifications** - Enable browser reminders
   - ☕ **Support Development** - Optional donation link

### Daily Use:

1. **Open the app each morning** (or whenever you want)
2. **Complete each habit** by clicking the green circle ○
3. **Watch it turn to a checkmark** ✓
4. **In ADHD mode:** Get a celebration! 🎉
5. **See your streaks grow** 🔥

### Using ADHD Mode:

1. **Open Settings** (gear icon)
2. **Toggle "ADHD Support Mode" ON**
3. **Now you get:**
   - Celebration animations when completing habits
   - More encouraging language everywhere
   - Gentle reminders and positive reinforcement
   - Compatible with Focus Mode for extra support

### Using Focus Mode:

1. **Open Settings** (gear icon)
2. **Toggle "Focus Mode" ON**
3. **See only incomplete habits** - reduces overwhelm
4. **Complete a habit** - it disappears from view
5. **Banner shows at top** with "Exit" button
6. **When all done** - special celebration message!

### Editing Habits:

1. **Find the habit card**
2. **Click the pencil icon (✏️)**
3. **Modify name, icon, category, or reminder time**
4. **Click "Update Habit"**
5. **All your progress is preserved!**

### Tips for Success:
- Start with 3-5 habits (don't overdo it!)
- Check in at the same time daily
- Use Focus Mode if you get overwhelmed
- Enable ADHD Mode if you need extra encouragement
- Set reminder times to help with time blindness
- Place app icon on home screen for easy access
- Celebrate your streaks!

## 🐛 Troubleshooting

### App not loading?
- Clear your browser cache
- Make sure all files are in the same folder
- Check browser console (F12) for errors

### Data disappeared?
- Data is stored in your browser
- Clearing browser data will reset the app
- Each browser/device has separate data

### Can't install as app?
- Must use HTTPS (hosting services provide this)
- Some browsers don't support PWAs
- Try Chrome or Safari

### Need to reset everything?
- Open browser developer tools (F12)
- Go to Application → Storage → Local Storage
- Delete 'habits' and 'habitCompletions'

- **LocalStorage API** - Data persistence

- **Toggle System** - Feature flags for ADHD/Focus modes
- **Celebration Animations** - CSS keyframes & transitions
- **Modal System** - Settings interface
- **Data Persistence** - localStorage with JSON
- **Responsive Design** - Mobile-first approach
- **Accessibility** - ADHD-friendly UX patterns
